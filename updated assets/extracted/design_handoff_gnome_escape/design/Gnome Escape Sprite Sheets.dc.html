Where these fall short

  • No anti-aliased inner shading. A pixel artist would add a third value inside each gnome's body; the palette allows exactly two plus the ink outline, so the forms read flat by design. If that turns out too flat in motion, the fix is one extra ramp step per gnome — a palette change, not a redraw.
  • The faces are two pixels of eye. At 20×26 that is honest, but expression will need a pass once the animation timing is locked.
  • Stone's push cycle reuses the walk legs. It works, but a real push has both feet planted and a shoulder drive; that is a hand pass, not a composition.
  • No sink, break, jump, glide or gate frames yet. Those were not in this round's priority list.
